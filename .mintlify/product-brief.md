# Product brief

## Description

跨界 AI 是面向开发者的 AI 模型中转与 API 管理平台，提供统一的 OpenAI 兼容和 Anthropic 兼容入口。

## Primary audience

需要在 Codex、Claude Code、Gemini CLI、桌面客户端或自有程序中接入 AI 模型的中文开发者。

## Jobs to be done

- 在 `https://www.kuajieaigc.com` 注册并登录账户。
- 在控制台创建 API Key，并使用 `https://api.kuajieaigc.com/v1` 发起请求。
- 按客户端类型完成配置并排查常见连接、鉴权和模型问题。

## Motivation

跨界 AI 通过统一的 API 地址和账户控制台降低多模型接入成本，同时保留对开发者工具和标准 SDK 的兼容性。

> 说明：充值、退款、客服渠道和具体模型清单以跨界 AI 线上控制台实际展示为准，文档不预设未验证的价格或服务承诺。
