跨界 AI 的图像能力可能通过 OpenAI 兼容接口或任务插件提供。模型、输入格式、返回类型和价格因渠道而异，请先在模型广场确认当前开放的图像模型。

## OpenAI 兼容路径

- 生成：`POST /v1/images/generations`
- 编辑：`POST /v1/images/edits`

请求主机为 `https://api.kuajieaigc.com`。接口可用字段以目标模型的协议要求为准。

## 提交前检查

1. 确认账户分组可调用该模型。
2. 按客户端格式准备提示词和图像输入。
3. 查看模型详情中的计费单位。
4. 保存返回任务 ID 或结果，便于在日志中排查。
