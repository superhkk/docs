使用模型列表接口查看当前 API Key 可见的模型。返回内容受密钥分组、模型状态和平台配置影响，客户端不应把旧列表缓存为永久可用。

## 请求

`GET https://api.kuajieaigc.com/v1/models`

```bash
curl https://api.kuajieaigc.com/v1/models \
  -H 'Authorization: Bearer your-api-key-here'
```

返回结构遵循 OpenAI 兼容模型列表格式。请把返回的 `id` 用作后续请求的 `model` 值；如果某个模型没有出现在结果中，先检查密钥分组和模型广场中的当前状态。
