跨界 AI 提供统一的 API 地址。国产模型优先使用 OpenAI 兼容的 Chat Completions，Codex 等客户端可以使用 Responses，Claude Code 使用 Anthropic Messages，Gemini CLI 使用 Gemini 兼容路径。

除了在工具中使用，你也可以在自己的程序里直接调用跨界 AI。先创建 [API Key](/quickstart/api-key)，再根据客户端字段类型选择正确的 Base URL。模型 ID 请从[模型广场](https://www.kuajieaigc.com/pricing)复制。

## 接口格式

| 场景 | 接口 | 请求地址或 Base URL | API Key 厂商 |
| - | - | - | - |
| 国产模型、GPT、兼容 OpenAI 的模型 | OpenAI Chat Completions | `https://api.kuajieaigc.com/v1/chat/completions` | OpenAI |
| Codex 等 Responses 客户端 | OpenAI Responses | `https://api.kuajieaigc.com/v1/responses` | OpenAI |
| Claude Code、Claude 客户端 | Anthropic Messages | `https://api.kuajieaigc.com/v1/messages` | Anthropic |
| Gemini 原生客户端 | Gemini | `https://api.kuajieaigc.com/v1beta/models/{model}:generateContent` | Gemini |

请求头通过 `Authorization: Bearer your-api-key-here` 传入 API Key。Anthropic Messages 客户端也可以使用它要求的 `x-api-key` 形式。不同协议的地址不要混用。

## Chat Completions

国产模型和大多数桌面客户端使用 Chat Completions。完整的请求体、流式输出、工具调用、结构化输出、响应和错误说明见 [Chat Completions 参考](/api/chat-completions)。

```bash
curl --request POST \
  --url https://api.kuajieaigc.com/v1/chat/completions \
  --header 'Authorization: Bearer your-api-key-here' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "your-model-id",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

## OpenAI Responses

**curl**

```bash theme={null}
curl https://api.kuajieaigc.com/v1/responses \
  -H "Authorization: Bearer your-api-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "your-model-id",
    "input": [
      {
        "type": "message",
        "role": "user",
        "content": [
          { "type": "input_text", "text": "hi" }
        ]
      }
    ]
  }'
```

> [!NOTE]
>
> `input` 需要使用数组格式，如上例所示

**Python**

先安装官方 SDK：`pip install openai`

```python theme={null}
from openai import OpenAI

client = OpenAI(
    base_url="https://api.kuajieaigc.com/v1",
    api_key="your-api-key-here",
)

response = client.responses.create(
    model="your-model-id"  # 从模型广场复制实际模型 ID,
    input=[{"role": "user", "content": "hi"}],
)
print(response.output_text)
```

**Node.js**

先安装官方 SDK：`npm install openai`

```javascript theme={null}
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.kuajieaigc.com/v1",
  apiKey: "your-api-key-here",
});

const response = await client.responses.create({
  model: "your-model-id",
  input: [{ role: "user", content: "hi" }],
});
console.log(response.output_text);
```

## Anthropic Messages

使用 Anthropic SDK 时，请求地址**不加** `/v1`，SDK 会自动补全

**Python**

先安装官方 SDK：`pip install anthropic`

```python theme={null}
from anthropic import Anthropic

client = Anthropic(
    base_url="https://api.kuajieaigc.com",
    api_key="your-api-key-here",
)

message = client.messages.create(
    model="your-claude-model",
    max_tokens=1024,
    messages=[{"role": "user", "content": "hi"}],
)
print(message.content[0].text)
```

**Node.js**

先安装官方 SDK：`npm install @anthropic-ai/sdk`

```javascript theme={null}
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://api.kuajieaigc.com",
  apiKey: "your-api-key-here",
});

const message = await client.messages.create({
  model: "your-claude-model",
  max_tokens: 1024,
  messages: [{ role: "user", content: "hi" }],
});
console.log(message.content[0].text);
```

将 `your-claude-model` 替换为要使用的 Claude 模型 ID

## 地址检查

| 你看到的配置字段 | 应填写 |
| - | - |
| OpenAI SDK `base_url` / `baseURL` | `https://api.kuajieaigc.com/v1` |
| OpenAI 客户端完整 URL | `https://api.kuajieaigc.com/v1/chat/completions` |
| 主机和路径分开 | 主机 `https://api.kuajieaigc.com`，路径 `/v1/chat/completions` |
| Claude Code `ANTHROPIC_BASE_URL` | `https://api.kuajieaigc.com` |

如果请求返回 `404`，先检查是否重复写入 `/v1`，或者把完整接口路径误填进了只接受 Base URL 的字段。

## 常见问题

> **提示 401 或 API\_KEY\_REQUIRED**
>
> * 确认请求头中带有 `Authorization: Bearer your-api-key-here`
> * 确认 API Key 的厂商与调用的模型一致：GPT 用「OpenAI」，Claude 用「Anthropic」

> **提示 404**
>
> 检查请求地址：OpenAI SDK 的 `base_url` 需要以 `/v1` 结尾，Anthropic SDK 的 `base_url` 不加 `/v1`

> **连接超时或无法访问**
>
> 确认使用 `https://api.kuajieaigc.com`，路径规则不变
