AionUi 可组合多种 AI 工具与模型服务。为跨界 AI 添加自定义模型时，按具体连接类型选择 OpenAI 或 Anthropic 兼容协议。

- OpenAI 兼容地址：`https://api.kuajieaigc.com/v1`
- Anthropic 兼容地址：`https://api.kuajieaigc.com`
- 模型 ID：从[模型广场](https://www.kuajieaigc.com/pricing)复制
- API Key：从[控制台](https://www.kuajieaigc.com/keys)创建

客户端版本、可配置协议和代理子工具可能影响实际行为。先测试普通对话，再确认工具调用和多模态功能。
