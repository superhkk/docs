在 AQBot 添加模型提供方时，选择目标模型支持的协议，并填写对应地址与 API Key。

| 协议 | Base URL |
| --- | --- |
| OpenAI 兼容 | `https://api.kuajieaigc.com/v1` |
| Anthropic 兼容 | `https://api.kuajieaigc.com` |

模型名称使用模型广场中的 ID。发送简单文本请求后，再逐项测试工具调用、图片等能力。实际能力由具体模型和渠道决定。
