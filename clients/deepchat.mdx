---
title: "DeepChat"
description: "将 DeepChat 配置为使用跨界 AI 的 OpenAI 兼容模型服务。"
sidebarTitle: "DeepChat"
---

在 DeepChat 的模型服务管理中添加自定义服务商，选择 OpenAI 兼容模式并填写跨界 AI API 地址。

| 配置项 | 值 |
| --- | --- |
| API 地址 | `https://api.kuajieaigc.com/v1` |
| API Key | 你的跨界 AI API Key |
| 模型 | 模型广场中的模型 ID |

保存后选择新模型发起对话。若界面要求完整接口路径，请按该字段说明填写，不要重复追加 `/v1`。模型可用性受账户分组和渠道支持限制。
