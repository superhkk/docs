在 DeepSeek Harness 的自定义模型设置中选择与目标模型相符的协议，填写跨界 AI API 地址与密钥。不同版本界面可能不同，请以应用当前设置项为准。

## 配置地址

| 协议 | Base URL |
| --- | --- |
| OpenAI Chat Completions | `https://api.kuajieaigc.com/v1` |
| OpenAI Responses | 使用应用中的 Responses 接口设置 |
| Anthropic Messages | `https://api.kuajieaigc.com` |

模型名称使用[模型广场](https://www.kuajieaigc.com/pricing)中的模型 ID。添加后先发送简单文本请求，再测试工具调用等高级能力。协议和功能是否可用以模型详情及实际响应为准。
