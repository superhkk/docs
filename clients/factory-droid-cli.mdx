在 Factory Droid CLI 的自定义模型或兼容服务设置中填写跨界 AI API 地址、API Key 和模型 ID。请依据安装版本的官方配置界面选择兼容协议。

OpenAI 兼容 Base URL 为 `https://api.kuajieaigc.com/v1`；Anthropic 兼容客户端需按字段要求使用 `https://api.kuajieaigc.com`。不要把完整接口路径填进 Base URL。

先用模型广场已开放的模型验证普通文本请求，再配置工具调用等高级能力。
