description: "在 FluentRead 中配置自定义 OpenAI 兼容翻译服务，使用跨界 AI 模型完成翻译。"
sidebarTitle: "FluentRead"
---

在 FluentRead 的翻译服务设置中选择自定义 OpenAI 兼容服务，填写 API 地址、API Key 和可用模型 ID。

    Base URL: https://api.kuajieaigc.com/v1
    API Key: your-api-key-here
    Model: your-model-id

保存后选取一段非敏感文本进行测试。如果应用支持设置提示词，可按翻译场景调整。实际可用模型以模型广场和密钥分组为准。
