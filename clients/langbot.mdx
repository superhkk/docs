description: "为 LangBot 的模型提供方配置跨界 AI，使机器人通过兼容 API 调用模型。"
sidebarTitle: "LangBot"
---

在 LangBot 的模型提供方设置中添加自定义兼容服务，填写 API 地址、密钥和模型 ID。

    API Base URL: https://api.kuajieaigc.com/v1
    API Key: your-api-key-here
    Model: your-model-id

保存配置后在 LangBot 中运行测试或向机器人发送短消息。若使用 Anthropic 兼容提供方，请按客户端选项填写 Anthropic Base URL，并确认目标模型支持该协议。
