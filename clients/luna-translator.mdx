title: "LunaTranslator"
description: "为 LunaTranslator 配置兼容 API 服务，调用跨界 AI 模型进行文本翻译。"
sidebarTitle: "LunaTranslator"
---

在 LunaTranslator 的大语言模型或自定义 API 设置中选择 OpenAI 兼容接口，填写 Base URL `https://api.kuajieaigc.com/v1`、API Key 和模型广场中的模型 ID。

先使用短句测试连接和输出语言，再调整提示词及上下文长度。不同模型对长文本、流式输出和特殊字符的处理可能不同。不要将账户密码或 API Key 放进公开配置文件。
