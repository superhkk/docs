> Gemini CLI 安装与配置教程

## 环境准备

> [!NOTE]
>
> 请先完成 [环境配置](/environment/setup)，确保 Node.js 已正确安装

## 安装

**macOS**

**方法一：Homebrew（推荐）**

```bash theme={null}
brew install gemini-cli
```

**方法二：NPM**

```bash theme={null}
npm install -g @google/gemini-cli
```

**Windows**

在终端中运行：

```bash theme={null}
npm install -g @google/gemini-cli
```

**Linux**

在终端中运行：

```bash theme={null}
npm install -g @google/gemini-cli
```

## 配置

配置文件位于：

* **macOS/Linux**: `~/.gemini/`
* **Windows**: `C:\Users\你的用户名\.gemini\`

**创建 .env 文件**

```env theme={null}
GOOGLE_GEMINI_BASE_URL=https://api.kuajieaigc.com
GEMINI_API_KEY=your-api-key-here
GEMINI_MODEL=your-gemini-model-id
```

> [!WARNING]
>
> 将 `your-api-key-here` 替换为你的 API Key

## 使用

在终端运行 `gemini`，看到对话界面并能正常回复即表示配置完成

```bash theme={null}
gemini
```
