## 我们是谁

跨界AI 是一个专注为开发者提供高质量 AI 编程助手服务的中转平台，支持 Codex、Claude Code、Gemini 等主流 AI 模型

通过统一的 API 地址，将兼容模型接入到常用开发工具和客户端

## 核心优势

> **多模型支持**
>
> 支持 Codex、Claude Code、Gemini 等主流 AI 模型

## 快速开始

**1. 注册账号**

在官网创建你的账号

**2. 余额充值**

在控制台为账户充值余额

**3. 创建 API Key**

在控制台生成 API 密钥

**4. 配置 CLI**

使用 API Key 配置你的命令行工具

>
> 查看详细的注册和配置步骤
