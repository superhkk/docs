## 第一次 API 调用

<Steps>
  <Step title="注册并登录">从[官网](https://www.kuajieaigc.com/sign-up)创建账户。</Step>
  <Step title="创建 API Key">在[控制台密钥页面](https://www.kuajieaigc.com/keys)创建密钥并选择可用分组。</Step>
  <Step title="选择模型">从[模型广场](https://www.kuajieaigc.com/pricing)复制一个当前可用的模型 ID。</Step>
  <Step title="发送请求">使用 OpenAI 兼容 Base URL `https://api.kuajieaigc.com/v1` 发起请求。</Step>
</Steps>
