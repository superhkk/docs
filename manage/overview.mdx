跨界 AI 控制台支持创建个人访问令牌，用于脚本访问你自己的账户管理接口。个人访问令牌与调用模型的 API Key 用途不同：管理 API 使用控制台接口，模型推理则使用 API Key。

## 创建个人访问令牌

1. 登录控制台并打开个人资料或安全设置。
2. 找到访问令牌区域，选择创建令牌。
3. 设置名称、有效期和最小必要权限。
4. 完成页面要求的安全验证，并安全保存生成的令牌。

当前账户最多可创建 20 个令牌。界面提供 30 天、90 天、180 天、一年、自定义和永不过期等有效期选项；永不过期令牌会持续有效，建议设置到期时间。创建后可在同一区域修改权限、重命名或撤销令牌。

## 权限范围

令牌通过权限范围限制可访问的资源。常见范围包括：

| 范围 | 用途 |
| --- | --- |
| `profile:read`、`profile:write` | 查看或修改个人资料 |
| `api_key:read`、`api_key:write`、`api_key:reveal` | 查看、管理或读取 API Key |
| `wallet:read`、`wallet:write` | 查看钱包信息或执行受支持的钱包操作 |
| `usage:read` | 查看个人用量、日志和任务信息 |

可选权限以创建令牌时的权限目录为准。只勾选脚本确实需要的权限；完整密钥读取和写入类操作要特别谨慎。

## 调用管理接口

将个人访问令牌放入 HTTP Bearer 请求头，并使用跨界 AI 控制台域名访问对应 `/api/...` 路径。管理接口是控制台 API，不是 `/v1` 模型推理接口。可访问的路由由令牌权限范围决定，权限不足时应在令牌管理页调整授权。

个人访问令牌不能替代模型调用 API Key，也不要把令牌放进公开仓库或浏览器端代码。
