> 在控制台创建用于 CLI 工具的 API Key

## 创建步骤

**1. 登录控制台**

登录账号后访问 [https://www.kuajieaigc.com/keys](https://www.kuajieaigc.com/keys)

**2. 进入 API 密钥页面**

点击左侧菜单栏「API 密钥」

**3. 点击创建密钥**

在 API 密钥页面，点击右上角「创建密钥」按钮

**4. 填写密钥信息**

填写以下信息

* **名称**：为你的 API Key 起一个便于识别的名称
* **厂商**：选择要使用的模型厂商，如 Anthropic、OpenAI、国产模型或其他
* **分组**：选择该厂商下的可用分组，不同分组的倍率不同
* **自定义密钥（可选）**：使用自定义密钥
* **IP 限制（可选）**：限制只有特定 IP 可以使用此密钥
* **额度限制（可选）**：设置此密钥的额度上限，具体计量单位和无限额选项以页面显示为准
* **速率限制（可选）**：限制此密钥的请求频率
* **密钥有效期（可选）**：设置密钥的过期时间

> [!TIP]
>
> 使用 Claude Code 或 Claude Desktop 时，厂商选择「Anthropic」

**5. 创建成功**

点击「创建」后，系统会生成 API Key

> [!WARNING]
>
> **注意事项**
>
> API Key 是访问服务的凭证，请勿泄露给他人，建议为不同的项目或用途创建不同的 API Key

## 切换分组

同一个 API Key 可以切换分组。在「API 密钥」列表中，通过该密钥的分组下拉框直接切换，等待 1～2 分钟后再调用即可生效，无需修改工具中的配置
