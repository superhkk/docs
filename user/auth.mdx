跨界 AI 账户用于访问控制台。请通过官网的注册或登录入口操作，按页面要求填写资料并完成验证。认证方式和找回密码流程可能随站点设置变化，请以当前页面提示为准。

## 注册账户

<Steps>
  <Step title="打开注册页">访问[跨界 AI 注册页面](https://www.kuajieaigc.com/sign-up)。</Step>
  <Step title="填写信息">按页面表单要求填写账户资料。</Step>
  <Step title="完成验证">完成页面要求的验证并提交，随后登录控制台。</Step>
</Steps>

## 登录与账户恢复

从[登录页面](https://www.kuajieaigc.com/sign-in)进入账户。忘记密码时使用登录页面提供的找回入口；如无法完成验证，请使用官网当前展示的支持渠道。

> [!WARNING]
> 不要将账户密码、邮箱验证码、API Key 或个人访问令牌发给其他人。

完成登录后，前往[创建 API Key](/quickstart/api-key)并查看[接入地址速查](/guide/endpoints)。
