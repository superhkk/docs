兼容客户端通常需要设置 API 类型、Base URL 和 API Key。OpenAI 兼容模式通常使用 `https://api.kuajieaigc.com/v1`；Anthropic 兼容客户端按配置项使用 `https://api.kuajieaigc.com`。

## 通用配置

<Steps>
  <Step title="添加自定义服务商">在客户端中选择添加自定义或兼容服务商。</Step>
  <Step title="选择协议并填写地址">按客户端的协议字段填写跨界 AI 地址与 API Key。</Step>
  <Step title="添加模型并测试">使用模型广场的模型 ID，发送一条短消息验证连接。</Step>
</Steps>

模型是否可调用由账户权限、密钥分组、模型状态和协议支持共同决定。针对具体客户端，请查看[客户端接入](/clients/cherry-studio)中的对应页面。
