控制台首页用于集中查看账户概况和常用入口。具体指标及其展示范围由当前账户和站点配置决定；需要核对请求明细时，请进入用量日志页面。

## 常用入口

- [模型广场](https://www.kuajieaigc.com/pricing)：查看当前模型与价格。
- [API 密钥](https://www.kuajieaigc.com/keys)：管理调用凭证。
- [钱包](https://www.kuajieaigc.com/wallet)：查看余额与充值信息。
- [控制台首页](https://www.kuajieaigc.com)：查看当前账户提供的概览内容。

## 排查调用问题

当余额或调用状态与预期不一致时，记录请求时间、模型 ID 和错误信息，再查看[日志与异步任务](/user/log)。分享截图前请遮挡完整密钥。
