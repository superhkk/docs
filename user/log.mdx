控制台日志页面用于核对个人请求记录；异步任务是否出现取决于所用功能。日志字段、保留期限和筛选能力以当前控制台展示为准。

## 排查单次请求

1. 记录请求的大致时间和模型 ID。
2. 登录控制台打开日志或用量页面。
3. 按页面可用条件筛选，查看请求状态、耗时和返回信息。
4. 将日志中的错误与客户端错误响应一起核对。

分享日志截图前遮挡 API Key、用户标识和其他敏感字段。联系支持时，提供请求时间、客户端名称、模型 ID 和错误信息，不要直接发送密钥。

## 异步任务

图像或视频等任务型接口可能需要先提交任务，再查询状态或获取结果。具体地址请查看对应的[API 参考](/api/overview)。
