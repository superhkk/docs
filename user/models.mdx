调用模型前，请从登录后的模型广场复制当前可用的模型 ID。控制台的模型列表和价格页是模型名称、状态与定价的准确信息来源，文档不固定列出可能变化的型号。

## 查找模型

<Steps>
  <Step title="打开模型广场">前往[模型广场](https://www.kuajieaigc.com/pricing)。</Step>
  <Step title="搜索并确认模型">使用页面提供的搜索和筛选条件，查看模型详情、模型 ID、价格与支持能力。</Step>
  <Step title="复制模型 ID">将模型 ID 原样填入客户端的模型字段。不要用供应商后台的上游名称替代。</Step>
</Steps>

模型映射、渠道和用户分组由平台服务端处理。模型是否在列表展示不代表上游的全部能力都已开放；工具调用、图片输入和流式输出均需以模型详情及实际响应为准。

## 分组与可用范围

API Key 所属分组会影响可请求模型和计费规则。创建密钥时选择账户可用的分组；如果请求返回无权限或模型不可用，核对密钥分组和模型广场中的当前可用状态。

## 供应商筛选

如果模型卡片展示供应商信息，可使用页面筛选器缩小列表。筛选结果取决于平台维护的模型元数据；缺少供应商标签时，可直接搜索模型名称或 ID，并以模型详情为准。
