钱包页面显示账户余额和可用的充值入口。支付渠道、充值金额、到账状态和退款处理均以登录后控制台的当前说明为准。

## 充值

<Steps>
  <Step title="打开钱包">登录后前往[钱包页面](https://www.kuajieaigc.com/wallet)。</Step>
  <Step title="选择充值方式和金额">按页面当前提供的选项完成选择。</Step>
  <Step title="完成支付并核对订单">按支付页面提示付款，返回钱包查看余额或订单状态。</Step>
</Steps>

如果订单状态未更新，请保存订单号和付款凭证，再通过官网当前提供的支持渠道联系。请勿提交账户密码或完整 API Key。

API 请求计费依据模型、账户分组和控制台价格信息。可在模型广场查看当前价格，并在日志中核对请求记录。
